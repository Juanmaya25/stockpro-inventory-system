# 📦 StockPro — Sistema de Gestión de Inventario

Sistema Full Stack de gestión de inventario y almacén, desarrollado con React y tecnologías modernas.

## 🚀 Funcionalidades
- Dashboard con KPIs en tiempo real
- Gestión de inventario con alertas de stock
- Registro de ventas con cálculo automático
- Gestión de proveedores
- Reportes y analytics con gráficas
- Configuración de empresa

## 🛠️ Tecnologías
- **Frontend:** React, Recharts
- **Backend:** Laravel, Python
- **Base de datos:** MySQL
- **Estilos:** CSS-in-JS
